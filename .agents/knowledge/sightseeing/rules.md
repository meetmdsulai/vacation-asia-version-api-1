# Sightseeing Rules
Categories: ACTIVITY and SHOW. Activity supports sessions, SIC/Private, capacity/unit requirements, add-ons, restrictions, meals and pickup/drop. Show supports fixed times, seat categories/capacity and per-seat pricing.
Sightseeing confirmation is mandatory before quotation approval.
Private units = ceil(pax/unit capacity). Show availability is session + seat category.
Group travellers may choose different activities only within the same sightseeing place; do not split one group into unrelated simultaneous destinations.
Child uses configured child rate; otherwise adult rate.
Included pickup/drop covers those transport segments and must not be duplicated.
