# Core Workflows
Commercial: Requirement -> Quotation -> Review -> Hotel/Sightseeing confirmations -> Approved -> >=50% payment -> Booking.
Operations: Booking -> traveller/rooming -> restaurant confirmation -> transport confirmation -> vehicle/driver/guide allocation -> itinerary/vouchers -> travel.
Finance: Initial payment -> booking -> amendments/additional charges -> balance -> travel -> eligible agency/distributor credit -> collection -> reconciliation/settlement.
Keep these timelines separately observable.
