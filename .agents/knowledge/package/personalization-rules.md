# Package & Personalization Detailed Rules
- PKG-FIX-001 Fixed Package has predefined dates, places, components and itinerary; customer only enrolls/books it. No component customization.
- PKG-PER-001 Personalized Package replaces the former customer-facing term Dynamic Package.
- PKG-PER-002 Personalized Package asks for budget, pax and experience/preferences and automatically composes/ranks the best compatible components available under the business rules.
- PKG-PER-003 Personalized pricing is component-driven and recalculated when the composition changes.
- PKG-CUS-001 Custom Package lets customer/agent manually assemble requirements/components and uses component-driven repricing.
- PKG-OPT-001 Mandatory/optional component semantics apply to Personalized and Custom packages, not Fixed customization.
