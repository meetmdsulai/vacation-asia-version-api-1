# Package Rules
## Fixed
Dates, places and components are predefined/locked. Customer enrolls/books; no customization.
## Personalized
Customer provides budget, pax and experience preferences. System automatically composes/ranks compatible components. Component pricing recalculates; mandatory/optional components supported.
## Custom
Customer/agent manually assembles requirements/components. Component pricing recalculates; mandatory/optional supported.
Use `Personalized Package`, not the old customer-facing term `Dynamic Package`.
