# Pricing Contract
Supplier/net cost remains internal. External Agency/Distributor/B2C users receive only authorized final selling price.
FCT/Admin controls markups. Discussed examples (Agency 14%, B2C 20%, Distributor 12%) are configuration examples, never constants.
VAT can be inclusive/exclusive. Manual override preserves calculated price, adjustment, reason, actor/time and final price.
Personalized and Custom packages reprice from components. Amendments calculate financial deltas without destroying prior history.
