# Feature Development Workflow
1. Identify owning domain/agent and relevant rule IDs.
2. Load core/contracts + relevant knowledge.
3. Stop on NEEDS_CLARIFICATION/conflict.
4. Architecture Governor reviews cross-domain changes.
5. Database Architect reviews persistence changes.
6. Security reviews sensitive/payment/external exposure.
7. QA defines rule-based tests.
8. Update registry/knowledge only when product owner approves a new rule.
